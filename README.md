# CNN Optimization Techniques for MRI Brain Tumor Classification

## Project Overview
This project investigates optimization techniques for Convolutional Neural Networks (CNNs) used for MRI brain tumor classification.

## Objective
To study and compare CNN models and evaluate how optimization techniques affect classification accuracy and model complexity.

## Dataset
The dataset contains MRI brain images from four classes:
- Glioma
- Meningioma
- No Tumor
- Pituitary

## Models
The project report discusses the following CNN architectures:
- DenseNet-121
